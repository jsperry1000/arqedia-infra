## CP-03 · Citations without a page

| | |
|---|---|
| Status | Not investigated |
| Priority | High. It is the root of two other symptoms |
| Type | Extraction |

`_citation` falls back to a bare filename when `locator_index` is null. Those
are values the extractor returned with no unit.

**It causes the consolidation drops.** The same document appears twice in one
section, once with a page and once without; the model merges and keeps the
page-level one. Fix the unit and the redundancy disappears.

Measure first: what proportion of `extracted_value` rows carry
`locator_kind = 'none'`, and whether they cluster by handler or by document
type.

## TPL-02 · Importing a pack memorandum into an existing tenant

| | |
|---|---|
| Status | Design only |
| Priority | Not now. Recorded so the constraint is not lost |
| Type | Registry |

A pack edit never reaches a tenant who has forked — correct, and it means a
tenant cannot receive a fourth memorandum we ship later.

The answer is importing one memorandum from a pack revision into a tenant's
draft: copy its sections and bindings, refuse or offer to bring any field it
needs that the tenant lacks. **Possible only because the field vocabulary is
shared across packs**, which is why that decision was taken now.
