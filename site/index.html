What you configure, and what you can change afterwards.

Get the configuration right upfront

You configure the document types your business expects, and the facts each of those documents should carry. Design your reporting from the reports you already write: upload one, and ARQEDIA reads it and sets up the base configuration for you.

Single source of facts

Facts are extracted against your definitions and cannot wander from report to report. Composition can only use the facts your definitions produced.

Rearrange without re-reading

Add a section, retitle it, reorder it, include new facts. The change reaches newly generated reports without disturbing the fact structures you have already configured.

Version control

Configurations are tracked, and so are earlier versions of every report. Source documents can be updated, replaced or deprecated, and the record says which version of which configuration produced what.

What happens to a file you upload.

  1. Upload

    Drop a folder of scans, statements and correspondence.

  2. Classify

    The file is classified into a document type based on your configuration.

  3. Review

    You see the classified file and can revise its treatment before anything is filed.

  4. Extract

    Facts are extracted from the file according to its classification, which you configure.

  5. Compose

    Sections are configurable to carry specific facts, and you set the tone and content of each section as it drafts.
